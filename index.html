9/12（土）— 渋谷 → 白馬

DAY 1 東京観光ロゲイニング2026 ～渋谷再発見2days～ 渋谷2-22-6 幸和ビル 4F

写真でチェックポイント（約40ヶ所）を回って得点を集める、2〜3人1チームの街歩き競技。 下は 5時間の部（9:45スタート）で組んである。3時間の部なら全体が1時間前倒し・終了は14:15で、夕方の余裕はさらに1時間増える。

    渋谷駅で荷物を預ける

    会場に荷物預かりは無い（「会場内にて、自己管理」）。白馬用の一式を持って40ヶ所を歩くのは現実的でないので、ここで切り離す。

    推奨 → 東京メトロ 宮益坂中央改札付近（大700円 ×15／特大900円 ×1・計117台）。会場と同じ渋谷駅東側。詳細は §04

  2. 09:00

    持ち物：デジタルカメラ・保険証・コンパス・携帯電話・筆記用具

  3. 09:15

    競技説明（9:15–9:45）

    ここで解散。

  6. 15:25

    渋谷 → 大宮（湘南新宿ライン・直通）

    所要 35〜39分。16:50頃の便に乗れば大宮 17:30前後着で、新幹線まで15分以上のマージンが残る。 17:05を過ぎると余裕が10分を切るので、そこを実質の締切とみなす。

    土曜ダイヤの実発車時刻は未確認 → §05。乗換なしの1本なので、遅延しない限り読みやすい区間。

    58分。長野 18:47 着。夕食を車内で済ませるなら、大宮駅で買っておくのがいちばん確実（長野着後は温泉の閉店時刻と競合する）。

  9. 19:00

    合流・積み込みで15分弱みておく。ここから先は時刻表に縛られない。

    レンタカーなら営業所の受付終了時刻に注意（18:47着は多くの店で閉店間際）→ §05

  10. 20:00

    白馬 着 — 43.3km / 約1時間3分

    オリンピック道路（長野〜白馬を約1時間で結ぶ）。急勾配やヘアピンは少なく信号も疎で、夜間でも走りやすい部類。とはいえ山間路の夜間走行なので、余裕を持って出る。

  11. 20:15

  12. 21:00

    宿へ — 早く寝る

    翌朝は6時台に動く。装備の最終確認（ゼッケン・チップ・レイン・ライト）は寝る前に終わらせておく。

9/13（日）— 白馬

DAY 2 白馬国際クラシック 2026 — 12km 八方第二駐車場 発着

前日受付には行けない。当日受付が前提。

公式の前日受付は 9/12（土）12:00–17:00・八方第二駐車場。同じ時間帯に渋谷でロゲイニングをしているので物理的に不可能。車があっても変わらない。

救いは 当日受付（9/13 6:00〜各種目スタート30分前）があること。12kmは9:00スタートなので 8:30が受付の締切。 参加賞も受付時の受け渡しなので、朝に受け取ることになる。当日受付だけで本当に足りるか、大会事務局に1本入れておくのが安全。

  1. 06:30

    宿発 → 八方第二駐車場

    車なので朝の移動は読みやすい。会場に駐車場があるが、50km・29kmの選手が先に入っている時間帯（7:00 / 8:30スタート）なので、混雑を見込んで早めに出る。

  2. 07:00

    当日受付（6:00 開始 / 12kmは 8:30 締切）

    ゼッケン・計測チップ・参加賞をここで受け取る。初参加なので、締切の8:30ではなく7時台に済ませて余白を作る。

  3. —

    更衣室・荷物

    更衣室はスタート地点にあり。荷物はスタート・ゴール隣の八方文化会館——ただしスタッフ常駐なし。車があるので、貴重品は車に置くほうが早い。

  4. 09:00

    12km スタート（制限4時間 / 13:00）

    要求ペース 3.0km/h ＝ 全区間歩いても完走できる制限。コースの核心は岩岳への一本登りと、その後のテクニカルな下り。

    戦術：登りは歩く・下りで走る。前日に渋谷を5時間歩いた脚であることを織り込む。

  5. 13:00

    制限時間 / ゴール

    同日の他種目：50km 7:00発（制限11h）／29km 8:30発（7.5h）／6km 9:30発（2h）。

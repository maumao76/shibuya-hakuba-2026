どのルートで白馬に入るか

選択肢は3つ。JR あずさ経由・北陸新幹線経由・夜行バス。所要も金額も似ているが、風呂に入れるかどうかが分かれる。

9/12（土）— 渋谷

DAY 1 東京観光ロゲイニング2026 ～渋谷再発見2days～ 渋谷2-22-6 幸和ビル 4F

写真でチェックポイント（約40ヶ所）を回って得点を集める、2〜3人1チームの街歩き競技。 下のタイムラインは 5時間の部（9:45スタート）で組んである。3時間の部なら全体がちょうど1時間後ろ倒し・終了は14:15で、以降の余裕はさらに増える。

  1. 08:30

    渋谷駅で荷物を預ける

    会場に荷物預かりは無い（「会場内にて、自己管理」）。白馬用のザック一式を持って40ヶ所を歩くのは現実的ではないので、ここで切り離す。

    推奨 → 東京メトロ 宮益坂中央改札付近（大700円 ×15／特大900円 ×1・計117台）。会場のある渋谷2丁目に最も近い。詳細は §05

  2. 09:00

    受付（9:00–9:15）

    幸和ビル4F。参加賞はここで受け取り。更衣室は無い（トイレを使う）。

    持ち物：デジタルカメラ・保険証・コンパス・携帯電話・筆記用具

  3. 09:15

    競技説明（9:15–9:45）

    ルールとMAP配布。ここで作戦を決める。

  4. 09:45

    スタート — 競技（9:45–14:45）

    5時間。翌日が本番のレースなので、ここでの脚の使い方が翌朝に直接効く。獲得点数より、下りの階段と長時間の立ち歩きを抑える判断を優先したい。

  5. 15:00

    集計・表彰式（15:00–15:15）

    ここで解散。以降が本ページの本題。

  6. 15:25

    ロッカー回収 → 中目黒へ

    幸和ビルから宮益坂改札まで徒歩5分前後。東横線で中目黒へ1駅（約3分）。

  7. 15:45

    光明泉（中目黒）— 銭湯

    15:00開店。露天あり。1時間強で上がる。選択肢の比較は §04。

    目黒区上目黒1-6-1／中目黒駅 徒歩3分／15:00–25:00・不定休

  8. 17:10

    中目黒 → 渋谷 → 東京駅

    東横線＋山手線で約30分。17:45頃に東京駅着。ここで駅弁と翌朝の補給を買う（白馬着が21時過ぎなので、現地の店はほぼ閉まっている前提で動く）。

  9. 18:04

    北陸新幹線 はくたか573号 → 長野 19:40

    予備は 18:24 かがやき515号 → 長野 19:44（80分）。ただし次のバスまで16分しかないので、余裕を取るなら18:04。

  10. 20:00

    長野駅東口 → 特急バス（この日の最終便）

    春夏秋ダイヤ（4/1–11/30）は予約不要、当日窓口または車内で購入。所要 約1時間10分。これを逃すとその日のうちに白馬へ入れない。

  11. 21:10

    白馬 着 — 宿へ

    白馬駅前・白馬八方バスターミナルとも停車。翌朝の会場は八方第二駐車場なので、宿が八方側なら八方で降りる。

03

白馬へのルート — 3案

新宿から白馬への直通「あずさ」は 1日1本・朝8:00発だけ（白馬11:40着）。 夕方に東京を出る場合、選択肢は「松本乗継」「長野乗継」「夜行バス」の3つに絞られる。

推奨

C — 北陸新幹線 → 長野からバス

渋谷 15:25 →〔山手線 25分〕→ 東京  ·  東京 18:04 →〔はくたか573号 96分〕→ 長野 19:40  ·  長野駅東口 20:00 →〔特急バス 約70分〕→ 白馬 21:10頃

乗換2回・待ち時間に余裕あり。銭湯にも夕食にも手が届く唯一の案。 バスは予約不要（春夏秋ダイヤ）。概算 新幹線 約¥8,000台＋バス ¥2,500前後。 リスクは長野20:00が最終バスであることひとつに集約されるので、そこだけ守ればいい。

代替

A — あずさ → 松本・信濃大町 乗継

新宿 16:00頃 →〔あずさ〕→ 松本 18:40頃 →〔大糸線 19:15 信濃大町行〕→ 信濃大町 →〔20:21 白馬行〕→ 白馬 20:57

銭湯の時間が取れない。15:15解散から直行で新宿16時台のあずさに乗る必要がある。 乗換2回＋在来線1時間半で、到着はCとほぼ同じ。 さらに 17時以降の松本発に白馬直通は無く、確認できたのは平日ダイヤなので土曜の接続は要確認。積極的に選ぶ理由が薄い。

代替

B — 夜行バス（バスタ新宿 23:05）

バスタ新宿 23:05（5551便）→ 白馬 4:15–4:35頃  ·  当日受付 6:00–8:30 → スタート 9:00

東京で風呂も夕食もフルに取れて、宿代も浮く。 受付時刻には間に合う。ただしレース前夜の睡眠がバス座席になる。 運賃 ¥5,200–7,000＋夜行代 ¥2,000。初めてのトレイルレースの前夜としては勧めない——宿が取れなかった場合の最後の砦として置いておく案。

不可

D — 新宿15:05発の昼行バス

バスタ新宿 15:05 → 白馬八方 20:28

乗換なしで最も楽だが、15:15解散に10分間に合わない。3時間の部（14:15解散）でも渋谷→新宿の移動を含めて現実的でない。

9/13（日）— 白馬

DAY 2 白馬国際クラシック 2026 — 12km 八方第二駐車場 発着

前日受付には行けない。当日受付が前提。

公式の前日受付は 9/12（土）12:00–17:00・八方第二駐車場。同じ時間帯に渋谷でロゲイニングをしているので物理的に不可能。

救いは 当日受付（9/13 6:00〜各種目スタート30分前）があること。12kmは9:00スタートなので 8:30が受付の締切。 参加賞も受付時の受け渡しなので、朝に受け取ることになる。当日受付で本当に足りるか、大会事務局に1本確認しておくのが安全。

  1. 06:00

    当日受付 開始

    八方第二駐車場。ゼッケン・計測チップ・参加賞をここで受け取る。12kmの締切は8:30だが、初参加なら7時台に済ませて余白を作りたい。

  2. —

    更衣室・荷物

    更衣室はスタート地点にあり。荷物はスタート・ゴール隣の八方文化会館——ただしスタッフ常駐なし。貴重品は宿に置いていく。

  3. 09:00

    12km スタート（制限4時間 / 13:00）

    要求ペース 3.0km/h。全区間歩いても完走できる制限。コースの核心は岩岳への一本登りと、その後のテクニカルな下り。

    戦術：登りは歩く・下りで走る。前日に渋谷を5時間歩いた脚であることを織り込む。

  4. 13:00

    制限時間 / ゴール

    参考・同日の他種目：50km 7:00発（制限11h）／29km 8:30発（7.5h）／6km 9:30発（2h）。
